# Arios TV 0.15.36.1

- Improved automatic library discovery and foreground catch-up.
- Prioritized newly added content over metadata maintenance so large background
  refreshes do not delay new additions in other synchronized folders.
- Corrected unnecessary retry delays after playback pauses scanning.
- Added diagnostic timing to help distinguish detection, queue and discovery delays.

The source-date ordering for recently added movies and episodes is preserved.
OneDrive / SharePoint transfer presets and native multichannel audio components
remain unchanged.

Update without uninstalling. Existing library data, profiles, saved connections
and provider registrations are retained. The public TV APK omits private metadata
registrations. Application source code remains private.
