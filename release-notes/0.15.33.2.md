# Arios TV 0.15.33.2

- Improved scanner recovery after interrupted discovery, with atomic page checkpoints.
- Reduced repeated library reads where incremental synchronization is supported.
- Preserved completed library data when a scan is paused or a response is incomplete.
- Improved streaming handoff for seeking and resuming.
- Prioritized available full-HD renditions during streaming startup, while retaining adaptive recovery.
- Added safe diagnostic markers for scan recovery and playback transitions.

Update without uninstalling. Existing library data, watch history, connections
and saved provider registrations are retained. No manual library rescan is required.
Existing rclone transfer settings and native multichannel audio decoders remain
unchanged. Playback quality and availability still depend on the source and network.

The public TV APK omits private metadata registrations. The application source
code remains private.
