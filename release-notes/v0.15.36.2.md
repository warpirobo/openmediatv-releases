# Arios TV 0.15.36.2

- Added a compact confirmation before a seek switches playback modes. Canceling
  keeps the current playback unchanged, with normal controller auto-hide restored.
- Fixed episode-card scrolling in series details: the episode number and title
  stay visible along with the image, including series without cast information.

Preserves recent-item ordering by source date, automatic scanner improvements,
OneDrive / SharePoint transfer presets and native multichannel audio components.

Update without uninstalling. Existing library data, profiles, saved connections
and provider registrations are retained. The public TV APK omits private metadata
registrations. Application source code remains private.
