# Arios TV 0.15.26.6

- More robust Unicode filename identification without modifying actual file paths.
- TorBox catalog ordering by full release date, newest/oldest, popularity and original title A–Z.
- Retained resume artwork and recovery for legacy entries with known title identifiers.
- Diagnostic event when the alternative FFmpeg audio renderer is unavailable.
- Pinned-module rclone version in CI and native dependency checksum verification.

Android TV / Fire TV, armeabi-v7a, Android 7+. Update without uninstalling.
Public APK excludes private TMDB/TheTVDB registrations and preserves previously
saved keys. Clean installations require your own provider keys.
Compilation and signing verified; no functional/playback tests performed.
Native libraries unchanged. Arios TV application source remains private.
