# Arios TV 0.15.35

- Updated the playback engine to stable Media3 1.11.1, including fixes for
  Matroska seeking, HLS loading and playback stalls.
- Updated the native network toolchain with certificate-security maintenance.
- Improved embedded subtitle-font recognition and attachment-order handling
  while retaining bounded memory usage.
- Recently added movies and episodes now prioritize source file timestamps
  instead of scan order, with discovery time used when no valid date is available.
- Preserved the existing native multichannel audio decoders and passthrough
  settings, as well as the established OneDrive / SharePoint transfer presets.

Update without uninstalling. Existing library data, watch history, profiles,
connections and saved provider registrations are retained.

The public TV APK omits private metadata registrations. The application source
code remains private.
