# Arios TV 0.15.29

- One Download and update consent, verified download, and automatic continuation after granting installation permission.
- Official Android 12+ self-update eligibility, with system confirmation fallback when required by the OS/OEM. Silent installation cannot be guaranteed on older Android/Fire OS devices; security prompts are not bypassed.
- Separate idle-time source removal audit. Two complete absence checks at least 15 minutes apart are required; errors, timeouts, unreadable roots and incomplete listings do not confirm removal.
- Only configured library sources are inspected, in bounded rotating batches, yielding to playback and scans. Exact catalog rows are removed transactionally; no remote files, history, favorites or tracker data are deleted.
- Returning files remain discoverable. Unreadable branches require a successful ancestor listing that confirms the branch is absent.
- User Preferences includes adult-only Removed content history, with movie/series filters and up to 1,000 records from the last 30 days.
- Existing identification/delta behavior, rclone configuration import, native playback components and backup budgets remain unchanged. Additive catalog schema migration to version 11.

TV **armeabi-v7a**, Android 7 / API 24 or later. Update without uninstalling to preserve settings and saved provider registrations. The new installation flow applies after this version is installed; the transition update is performed by the previously installed version.

Only the public APK is attached. Private TMDB/TheTVDB credentials are not included. Application source remains private. Compilation, static review, metadata/signature checks and native-library hash comparison only; no functional/device/playback tests were performed.
