# Arios TV 0.15.36

- Corrected recently added movies and episodes to respect source file dates.
  Scanning an older file no longer makes it appear newer than existing content.
- Improved portable watched-history matching across libraries, including titles
  identified after history restoration. Added a history-only backup shortcut.
- Expanded Spanish subtitle-provider availability across supported sources.
- Added native dependency integrity verification during release preparation.

Update without uninstalling. Existing library data, profiles, saved connections
and provider registrations are retained. Established OneDrive / SharePoint
transfer presets and native multichannel audio decoders are preserved.

The public TV APK omits private metadata registrations. The application source
code remains private.
