# Arios TV 0.15.28.2

- Simplified provider selection: one standard checkbox row per usable configured provider; unconfigured placeholders are hidden, not erased.
- PlavioHD remains available through IPTV only.
- Full-screen catalog descriptions match the library's backdrop/gradient, poster, title, certification, rating, synopsis, cast and rounded action buttons. Sources occupies the More action position; My list and Trailer remain directly accessible.
- Movie/series/anime discovery and searches exclude future or undated releases based on the device's current full calendar date. Seasons and episodes follow the same rule. Released metadata does not guarantee stream availability.
- Manual Sources selection keeps the episode source list manual. Play retains preference matching.
- Playback/native components, rclone configuration import and backup limits remain unchanged.

TV **armeabi-v7a**, Android 7 / API 24 or later. Update without uninstalling to retain settings and preserved provider registrations. Fresh public installations require the user's own TMDB/TheTVDB registrations.

Only the public APK is attached; application source remains private. Release compilation, static review, signature/metadata verification and native-library hash comparison only. No functional/device/playback tests performed.
