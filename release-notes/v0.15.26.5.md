# Arios TV 0.15.26.5

- Optional TorBox alongside IPTV in Settings, retaining existing linked accounts.
- Per-profile TorBox favorites in My list.
- Hydra Torrents provider added.
- Subtitulamos.tv for series alongside OpenSubtitles, with explicit title, season, episode, language and release selection.
- Improved poster/background decoding and filtered scaling.

Android TV / Fire TV, armeabi-v7a, Android 7+. Update without uninstalling.
The public APK excludes private TMDB/TheTVDB registrations, retaining previously
saved keys. Clean installations require your own provider keys.
Compilation and signing verified; no functional/playback tests performed.
Arios TV application source remains private.

are available separately; release assets contain only the APK.
