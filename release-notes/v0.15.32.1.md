# Arios TV 0.15.32.1

- Simplify optional integration setup with official HTTPS authorization pages rather than private-IP pages with self-signed certificates. No local certificate exception or shared Wi-Fi is required for the updated flow.
- Keep explicit user consent and TV confirmation before saving authorized credentials. Retain private API-key entry through the application's own keyboard as an alternative.
- Improve authorization countdown, cancellation, expiry and rate-limit handling. Do not preconfigure a personal account or replace an existing primary account during setup.
- Refine preference matching and manual fallback handling while retaining existing defaults.
- Preserve saved configurations, existing source imports, subtitle discovery, multichannel audio and libass. The unused local setup listener and certificate-generation dependency have been removed.

TV **armeabi-v7a**, Android 7 / API 24 or later. Update without uninstalling to retain your preferences and saved registrations.

Only the public APK is attached. Private TMDB/TheTVDB credentials are not included; new installations need their own registrations. Application source remains private.

Validation: successful local release compilation and 20 automated tests using synthetic authorization responses, preference matching and subtitle/configuration cases. No personal account or live sign-in was used; upstream plan requirements, service availability and physical-device behavior still require user verification.
