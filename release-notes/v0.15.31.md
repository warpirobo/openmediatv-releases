# Arios TV 0.15.31

- Automatically look up configured-language subtitles after playback starts when an identified movie or episode has no subtitle tracks. Embedded ASS/SRT/bitmap tracks, explicit Off and manual choices retain priority.
- Use OpenSubtitles v3 by IMDb title and episode ID, with Subtitulamos.tv fallback for a unique exact series match and exact season/episode. Respect the active subtitle language/type and secondary preference pairing. Ambiguous titles and unverified forced-subtitle matches remain manual choices.
- Bounded, asynchronous lookup; cancel stale work on exit or episode changes. Preserve current position and pause/play state when attaching downloaded text. Attaching can briefly rebuffer; subtitle timing still depends on the matching release.
- The shared subtitle downloader now supports bounded validated HTTPS redirects, public-address checks, download/decompression limits and the existing bounded cache. No account credentials are sent to subtitle providers.
- Improve the independent removal audit: ordinary OAuth token refresh no longer erases confirmation evidence, bounded folders rotate more frequently while idle, and inaccessible pending folders yield to other work. Two complete checks at least 15 minutes apart are still required; connection failures never authorize removal.
- Add removal progress/counters to diagnostics. Preserve remote files, history, favorites, existing scanner behavior, rclone.conf import, backup budgets and native playback components, including multichannel audio and libass.

TV **armeabi-v7a**, Android 7 / API 24 or later. Update without uninstalling to retain your preferences and saved provider registrations.

Only the public APK is attached. Private TMDB/TheTVDB credentials are not included; new installations need their own registrations. Application source remains private.

Compilation, static review, metadata/signature verification and native-library comparison only. Provider metadata/response headers were inspected read-only; no functional/device/playback tests were performed.
