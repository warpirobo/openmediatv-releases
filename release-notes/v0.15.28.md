# Arios TV 0.15.28

## Changes

- Per-profile preferred source quality, audio language, subtitle language and subtitle type under User Preferences.
- Catalog title descriptions with artwork, synopsis, cast, certification, rating and the existing in-app trailer player.
- Play selects the first declared matching cached torrent in provider order. Series select a season and episode first. Cache checks are batched; no uncached downloads are started.
- Missing language/subtitle declarations, ambiguous episode packs or unavailable matching torrents retain manual source/exact-file selection. Source labels are discovery hints, not a verified MKV track inventory.
- PlavioHD Live Sports within IPTV, with bounded logo loading, fitted channel/event artwork and compact league/category/status information.
- Adaptive artwork cache, safe Play-focus requests and precompiled Unicode filename normalization.
- Rclone configuration import, native playback libraries, eight-channel decoding, subtitle rendering and backup limits are unchanged.

## Installation and updates

TV release: **armeabi-v7a**, Android 7 / API 24 or later.
Update without uninstalling to retain settings and previously saved provider registrations.
The public APK excludes private TMDB/TheTVDB credentials. Fresh installations require the user's own registrations.
Only the APK is attached to this release. Application source remains private.

## Verification

Release compilation, static checks, APK metadata/signature verification and native-library hash comparison only. No functional/device/playback tests were performed; device testing is left to the user.
