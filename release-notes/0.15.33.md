# Arios TV 0.15.33

- Expanded library and profile-history backup compatibility.
- Retained watch history for titles that are added to the library later.
- Improved exact content matching and source/version selection for duplicate titles.
- Reduced background interface interruptions and streamlined playback transitions.
- Preserved existing rclone connection setup, OneDrive tuning and multichannel audio decoding.

Update the normal app without uninstalling to retain its settings and saved
provider registrations. Keep a backup before migrating library data.

The public TV APK contains no private TMDB/TheTVDB registrations. Existing saved
registrations remain supported; new installations need their own registrations.
The application source code remains private. Playback compatibility still
depends on the source, file, device and audio setup.
