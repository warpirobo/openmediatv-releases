# Arios TV 0.15.32.2

Improved playback diagnostics for investigating loading interruptions and read-only source access failures.

- Automatic playback journal with a rolling 30-day window and a total diagnostic storage limit of 20 MB. Oldest records are removed first when the limit is reached.
- More detailed source-open, player preparation, buffering and recoverable connection error records.
- Passive observations help distinguish local playback errors from Microsoft Graph, SharePoint, authentication and CDN responses.
- Only allowlisted service error codes are recorded. Raw URLs, account names, cookies, tokens and response bodies are not exported.
- Existing playback settings, audio decoding, scanning and rclone.conf import behavior are unchanged.

This release adds diagnostic evidence; it does not bypass provider access or download restrictions. Functional validation is performed by the user.

Install over your existing TV installation without uninstalling. After reproducing a problem, open User preferences > Diagnostics and export the diagnostic ZIP. Capture is automatic.

The public APK contains no private metadata keys. Existing saved registrations and preferences are retained during an update. New installations require their own metadata provider credentials.
