# Arios TV 0.15.33.1

- Fixed a startup timeout that could discard buffered video on slow connections.
- Improved playback priority over background monitoring and local history migration.
- Protected playback state when switching between player screens.
- Added clearer source/version selection rows with service icons.
- Improved safe diagnostic details for interrupted stream reads.

Update without uninstalling. Existing library data, watch history, connections
and saved provider registrations are retained. No library rescan is required.
Existing rclone transfer parameters and native multichannel audio decoders remain
unchanged. Source/network availability can still affect playback.

The public TV APK omits private metadata registrations. The application source
code remains private.
