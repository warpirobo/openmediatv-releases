# OpenMediaTV — descargas

Repositorio dedicado a distribuir APK y notas de versión de OpenMediaTV.
El código de la aplicación se mantiene en un repositorio privado separado.

Los instaladores se publicarán en la sección **Releases**. Este repositorio
no debe recibir el ZIP del proyecto, credenciales, configuraciones personales
ni claves de firma.

Las versiones públicas incluyen el actualizador integrado. Consulta la sección
Releases para descargar la APK Android TV (armeabi-v7a).

La APK pública no incluye claves privadas de TMDB/TheTVDB. En una instalación
nueva se pueden registrar las claves propias desde los ajustes de proveedores.
Las instalaciones existentes conservan las claves que ya hayan sido guardadas
localmente por una versión puente; actualizar no borra los datos de la aplicación.
No desinstales la aplicación antes de actualizar.

El canal de actualización está en `update.json`. Cada actualización requiere
confirmación del usuario y el instalador del sistema. El código de Arios TV
permanece privado. Las fuentes correspondientes de FFmpeg y sus instrucciones
de compilación se adjuntan a los releases públicos por sus condiciones LGPL.

Una vez disponible, instala ese primer APK manualmente. Desde él podrás comprobar
versiones posteriores en **Ajustes → Actualizaciones de la aplicación**, descargar
con confirmación e instalar mediante el instalador del sistema. La disponibilidad
de la instalación depende del dispositivo y de sus restricciones.
