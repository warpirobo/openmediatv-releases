# OpenMediaTV — descargas

Repositorio dedicado a distribuir APK y notas de versión de OpenMediaTV.
El código de la aplicación se mantiene en un repositorio privado separado.

Los instaladores se publicarán en la sección **Releases**. Este repositorio
no debe recibir el ZIP del proyecto, credenciales, configuraciones personales
ni claves de firma.

Todavía no hay un APK público ni un canal de actualización activo. La primera
publicación incluirá el actualizador integrado y se anunciará cuando estén
resueltos los requisitos de protección de los registros de proveedores.

Una vez disponible, instala ese primer APK manualmente. Desde él podrás comprobar
versiones posteriores en **Ajustes → Actualizaciones de la aplicación**, descargar
con confirmación e instalar mediante el instalador del sistema. La disponibilidad
de la instalación depende del dispositivo y de sus restricciones.
