# FFmpeg corresponding source

The archive in this directory contains the unchanged FFmpeg 6.1.6 source,
Media3 audio bridge, notices, configuration and build recipes corresponding to
the FFmpeg libraries in Arios TV 0.15.26.5, 0.15.26.6 and 0.15.27.

It is **not the Arios TV application source**, which remains private.
The archive was previously attached to the releases; moving it here keeps
release assets APK-only without removing access to component source.

Archive SHA-256: `17f5977b4240c42a51dcc3d5186978d3394fb0e2f356c51cb7e7a70af82d6700`.

See https://ffmpeg.org/legal.html and the license texts within the archive.
